# levelup-pomodoro
A easy-to-use, add-free fun timer that keeps tracks of your devotion in certain fields.

初次使用：先给自己添加“新技能”，然后在左上角设置基本的专注奖励信息，随后返回主界面1.点击想要提升的技能， 2.点“开始专注”  即可开始积累经验！

其他功能：
1.“还在吗”确认：灵感来自forest APP但更加灵活。通过右上角可以设置一个check time，每隔一段时间番茄钟会发出提示音和弹窗，检查你是否还在专注。请在一分钟内回应，否则会自动结束当前专注并结算经验。这可以最大程度保证你的每一点经验都是货真价实的！

2.“目标”额外bonus经验：可以给自己设定目标和奖励，并在完成时自动奖励对应的经验。注意：任何skill都要由时间打磨才能锋利，因此此功能只能作为辅助的激励。软件已经内置了“过去7天通过目标bonus经验” ≤ “过去7天通过专注获得经验的50%” 的限制，请合理使用避免“通货膨胀”！

3.成就系统：本软件的成就均为动态成就。持续的付出会点亮越来越多的成就，而半途而废会让已点亮的成就熄灭。 轻松开始，然后尽量坚持得久一点，看看自己真正的实力！

4.日志：主界面最下方可以查看近30日的升级数据。一个月后是成就感满满还是有些遗憾？全看当下的投入！
